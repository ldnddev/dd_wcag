dd_wcag 0.9.5

WCAG 2.x and APCA contrast checker, plus an SCSS palette builder. The same checker runs in the terminal (dd_wcag) and in a desktop window (dd_wcag-gui).

Install

Pin this release, or omit --version to take the latest package:

curl -fsSL https://raw.githubusercontent.com/ldnddev/dd_wcag/master/install.sh | bash -s -- --version v0.9.5

With no flag, the installer asks for the terminal, the window, or both. A non-interactive shell installs the terminal.

Guide

Illustrated tutorial covers setup, Contrast, Fix, Palette, and theming.
